# Bell to Bell

Игра для пары по теме "The structure of foreign language lesson and its organizing".
Каждый студент играет сам со своего телефона, результат уходит на сервер, преподаватель видит общую таблицу.

## Что внутри

- `server.js` — сервер на Node.js без зависимостей (Node 18+).
- `public/index.html` — игра для студентов (2 раунда: Puzzle и Sort).
- `public/results.html` — таблица результатов для вас.
- `data/results.json` — создаётся сам, здесь хранятся результаты.

## Адреса

- `/` — игра, эту ссылку раздаёте студентам.
- `/results?key=ВАШ_КЛЮЧ` — таблица результатов, обновляется каждые 5 секунд.

## Запуск локально

```
TEACHER_KEY=moy-sekret node server.js
```

Откройте http://localhost:3000 и http://localhost:3000/results?key=moy-sekret

Если `TEACHER_KEY` не задан, сервер придумает случайный ключ и напечатает его в логе при старте.

## Деплой на Render

1. Залейте папку в новый репозиторий на GitHub.
2. Render → New → Web Service → выберите репозиторий.
3. Build Command: `npm install`, Start Command: `npm start`.
4. Environment → добавьте переменную `TEACHER_KEY` со своим секретным словом.
5. После деплоя откройте `https://ваш-сервис.onrender.com/results?key=ВАШ_КЛЮЧ`.

## Важно про бесплатный план Render

- Сервис засыпает без запросов. Откройте игру за пару минут до пары, чтобы он проснулся.
- Диск не постоянный: после перезапуска или засыпания результаты пропадают.
  Сразу после игры нажмите "Show as CSV" на странице результатов и скопируйте таблицу.

## Очки

- Puzzle: +10 за верный этап, −5 за ошибку, максимум 70.
- Sort: +10 за верную карточку, максимум 120.
- Оценка: 5 от 90%, 4 от 72%, 3 от 50%, иначе 2.
